# OPTE RouteCache — Interactive Walkthrough

An independent, interactive explanation of the per-flow RouteCache and the proposed shared prefix-hop-set cache for [oxidecomputer/opte issue #539](https://github.com/oxidecomputer/opte/issues/539).

The visualization is an educational companion to the pull request, not executable code from OPTE and not part of the kernel module.

## GitHub Pages

In this repository open **Settings → Pages**, choose **Deploy from a branch**, set **main** and **/(root)**, then save. The entry point is `index.html`.

Expected site URL if this repository is named `ftpedroni/opte-routecache-explainer`:

`https://ftpedroni.github.io/opte-routecache-explainer/`

Verify the site is live before linking it from a pull request.
